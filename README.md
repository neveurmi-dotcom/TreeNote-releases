# TreeNote

macOS용 계층형(트리) 노트 앱 TreeNote의 설치 파일을 받는 곳이에요. 소스 코드는 이 저장소에 없어요.

👉 **[최신 버전 내려받기](https://github.com/neveurmi-dotcom/TreeNote-releases/releases/latest)**

## TreeNote 설치 방법

macOS 14(소노마) 이상, Apple 실리콘(M1 이후) Mac에서 쓸 수 있어요.

### 1. 내려받기
아래 **Assets**에서 `TreeNote-버전.dmg`를 눌러 내려받아요.

### 2. 설치
1. 내려받은 DMG를 더블클릭해서 열어요.
2. 창에 보이는 **TreeNote**를 옆의 **응용 프로그램** 폴더로 끌어다 놓아요.
3. DMG 창을 닫고, Finder 왼쪽의 DMG 꺼내기(⏏) 버튼을 눌러요.

### 3. 처음 열기 (한 번만)
TreeNote는 개인이 만든 무료 앱이라 Apple 유료 인증을 받지 않았어요. 그래서 처음 열 때 경고가 나와요.

1. **응용 프로그램** 폴더에서 TreeNote를 더블클릭해요.
2. "‘TreeNote’을(를) 열 수 없습니다" 또는 "Apple이 확인할 수 없습니다" 창이 뜨면 **완료**(또는 취소)를 눌러요.
3. **시스템 설정 › 개인정보 보호 및 보안**을 열고 아래로 내려요.
4. "TreeNote이(가) 차단되었습니다" 옆의 **그래도 열기**를 눌러요.
5. Mac 암호(또는 Touch ID)를 넣고, 다시 뜨는 창에서 **열기**를 눌러요.

이제부터는 그냥 더블클릭하면 열려요.

### 4. 업데이트
새 버전이 나오면 앱이 하루에 한 번 확인해서 **"새 버전이 있어요"** 창을 보여 줘요. **설치**를 누르면 알아서 바뀌어요.
직접 확인하려면 메뉴 막대의 **TreeNote › 업데이트 확인…**을 눌러요.

### 노트는 어디에 저장되나요?
처음 실행할 때 **새 데이터베이스**를 만들면, 고른 위치에 `.tdbn` 파일 하나로 저장돼요.
자동 백업은 **문서 › TreeNote 백업** 폴더에 하루 한 번 만들어져요(설정 › 백업·버전에서 바꿀 수 있어요).

### AI 비서를 쓰려면
설정(⌘,) › **AI 연결**에서 고를 수 있어요.
- **Claude 구독(Pro/Max)**: 이 Mac에 Claude Code가 설치되어 로그인돼 있으면 추가 비용 없이 써요.
- **Claude API / OpenAI 호환**: 각 서비스의 API 키를 넣어요(쓴 만큼 요금이 들어요).
